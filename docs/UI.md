# UI 设计参考

## 卡牌设计

所有卡牌统一尺寸 160×240px，扑克风格布局：
- 左上角：域图标（类似花色）+ 域标签
- 中央：技术品牌图标（Iconify API, 48px）
- 卡名居中
- 标签固定两行高度
- 底部：属性值 + 容量
- 右下角：域图标（半透明）

### 域颜色
| 域 | 颜色 | 图标 |
|---|---|---|
| 计算 | 蓝 #3b82f6 | lucide:cpu |
| 数据 | 绿 #22c55e | lucide:database |
| 网络 | 琥珀 #f59e0b | lucide:network |
| 防御 | 红 #ef4444 | lucide:shield |
| 平台 | 紫 #a855f7 | lucide:gauge |

## 出牌界面 (PlayScreen)

### 布局
- **左侧栏** (320px)：盲注信息 → 分数面板 → 金币 → 手牌/弃牌数 → 约束 → 牌型预览
- **顶部栏**：Joker 槽位（左）+ 塔罗槽位（右）
- **中部**：部署区（已出的牌）
- **下部**：手牌区（扇形弧度展开）+ 牌堆
- **底部**：弃牌 / 出牌按钮

### 手牌交互（Balatro 风格）
1. 点击卡牌 → 选中，向上弹出 30px
2. 再次点击 → 取消选中
3. 悬停 → 上浮 16px，保持弧度旋转，z-index 最高
4. 手牌扇形展开，10 张牌堆叠在 ~900px 内
5. 弧度：cos 曲线垂直偏移 + 旋转（±10°）

### 操作按钮
- **弃牌**：选中后点击弃牌，最多 5 张/次，显示剩余次数
- **出牌**：选中后点击出牌，最多 5 张（deploy slots），立即算分进入结算
